# Historical coursework showcase

`latest_run/` retains the original coursework run and selected images. It is not the current policy evaluation. Its map overlays and algorithm-analysis graphics were produced by an earlier implementation and should not be used as measured policy effects, live parking availability, or validated complexity/performance guarantees.

Use the [dated controlled evaluation](../docs/evaluation/README.md) and [public report](https://jeremy-cleland.github.io/parking_optimization/) for current charts, paired seed comparisons, reproducibility instructions, and limitations.
